# MMR Page

This GitHub Pages site presents the video results for *Morphology-Aware Human Motion Retargeting for Wheeled-Humanoid Loco-Manipulation*.

- **1. TAMR:** 20 retargeted motion sequences.
- **2. T-FeaCG + PPO:** five sequences with T-FeaCG and five sequences without T-FeaCG.

The page is deployed from the `main` branch through GitHub Pages.
